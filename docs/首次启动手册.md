# 首次启动手册（照着点，一路到游戏画面）

前提：手机是 **arm64（64 位）**、**Android 8.0 及以上**、能联网。
下面每一步都写了「看到什么算成功」和「没成功怎么办」。

---

## 第 1 步：装 APK

1. 把 `成品/FCLauncher-debug.apk` 传到手机（或用 `adb install -r FCLauncher-debug.apk`）。
2. 点击安装，允许「安装未知应用」。
3. 桌面出现 **豆包MC启动器** 图标，点开。

> 装不上报「解析包错误」：说明手机是 32 位（armeabi-v7a），本包只打了 arm64，需要重新编 32 位。

---

## 第 2 步：授权所有文件访问（必须）

游戏要读写 `/sdcard/games/Minecraft/`，Android 11+ 只能靠「所有文件访问权限」。

1. App 首页点 **授权**（或者系统会自己弹）。
2. 跳到系统设置里的「所有文件访问权限 / All files access」页面 → 找到「豆包MC启动器」→ 打开开关。
3. 返回 App，首页顶部的红字提示消失，显示 **存储：已授权**。
4. 再点一次 **授权通知**（Android 13+ 需要，下载进度要在通知栏显示）。

> 没授权会怎样：下载到一半报 `EACCES`，或者版本列表一片空白。

---

## 第 3 步：装 Java 17 到 `app_runtime/java/jre17`

App 内置「JRE 安装」页，直接用 Pojav 的预编译包（arm64）。

1. 首页 → 右上角设置/齿轮（或首页的「JRE」卡片）→ 进入 **JRE 管理**。
2. 选 **Java 17** → 点 **下载并安装**。
   下载地址是 Pojav 官方发布的 `jre17-arm64-*-release.tar.xz`（约 20MB）。
3. 等进度条走完（解压需要 1~2 分钟）。
4. 状态变成 **已安装（Java 17）**。

安装位置（**由 `context.getDir()` 动态算出，不写死包名**）：

```
/data/data/<你的包名>/app_runtime/java/jre17/
├── release
├── bin/java
└── lib/aarch64/server/libjvm.so
```

FCL 只认这个位置（`FCLPath.java` 里 `JAVA_17_PATH = getDir("runtime",0)/java/jre17`）。

> 手动放也行：用文件管理器把 Pojav 的 `jre17` 整个目录（解压后的，不是 tar.xz）拷到上面的路径。
> 根目录必须能看到 `release` 文件，否则会被判为「没装」。

**Java 版本对照**（装错版本，游戏会报 `UnsupportedClassVersionError`）：

| MC 版本 | 需要的 Java |
|---|---|
| 1.12 及以下 | Java 8（`app_runtime/java/jre8`） |
| 1.13 ~ 1.20.4 | **Java 17**（本手册这一条） |
| 1.20.5 及以上 | Java 21（`app_runtime/java/jre21`，Pojav 没有现成 21，需要 Zulu/Temurin 的 arm64 包） |

---

## 第 4 步：下载 1.20.1

1. 首页版本列表会从 BMCLAPI 拉到全部版本（几百条），搜索框输入 `1.20.1`。
2. 点 **1.20.1** 卡片 → **下载**。
3. 下载内容：`client.jar`（约 23MB）+ 88 个 libraries + 声音资源（约 650MB）+ 版本 json。
4. 通知栏能看到总进度；卡片颜色从灰 → 橙（缺东西）→ **绿（就绪）**。
5. 落到 `/sdcard/games/Minecraft/`：

```
/sdcard/games/Minecraft/
├── versions/1.20.1/1.20.1.jar
├── versions/1.20.1/1.20.1.json
├── libraries/...
└── assets/...
```

> 卡在某个库下载失败：说明镜像那个文件没同步，点卡片上的 **重试**，会跳过已下载的文件接着下。

---

## 第 5 步：选渲染器（默认 GL4ES，不用动）

首页 → 设置 → **渲染器**：

- **GL4ES（默认，最稳）** —— 老设备/中端机首选，大部分 Adreno/Mali 都能跑
- VGPU —— 少数设备更稳，需要额外驱动文件
- Zink —— 需要 Vulkan 4.6 级支持，新旗舰才建议试

第一次先别改，就用 GL4ES。

---

## 第 6 步：点「启动」

1. 卡片变绿后，点 **启动**。
2. 第一次启动会看到：
   - 一段黑屏 + 顶部状态栏提示「正在挂载运行时」（1~30 秒，属正常）
   - 然后是 Mojang 的红色 LOGO，接着进主菜单
3. 如果 30 秒后还是黑屏，按下面排查。

---

## 黑屏 / 闪退排查（按顺序看）

| 现象 | 原因 | 处理 |
|---|---|---|
| 点启动没反应，直接回首页 | JRE 没装或目录不对 | 回第 3 步，确认 `app_runtime/java/jre17/release` 存在 |
| 黑屏但状态栏有通知 | 渲染器没加载成功 | 换成 VGPU 试；`adb logcat \| grep -i "POJAV_RENDERER\|gl4es"` 看有没有加载失败 |
| 闪退 + `UnsatisfiedLinkError` | 装的是 32 位包 / so 没进 apk | 换 arm64 包；`unzip -l xxx.apk \| grep libpojavexec` 确认有 `lib/arm64-v8a/` |
| 卡在「Downloading Minecraft」 | 首次启动要补资源 | 等 1~2 分钟；网络断了就重试 |
| 报 `java.lang.UnsupportedClassVersionError` | Java 版本和 MC 不匹配 | 1.20.1 要用 Java 17 |
| 报 `Out of memory` | 内存给太多 | 设置里把内存调到 1024~1536MB |

日志位置：

```
/sdcard/FCL/log/latest.log        ← 游戏日志（FCL 后端写的）
adb logcat -s FCL:*              ← 原生层日志
```

---

## 全流程最短路径（一览）

```
装 APK → 授权「所有文件访问」 → JRE 页装 Java 17（落 app_runtime/java/jre17）
      → 版本列表搜 1.20.1 → 下载（等绿）
      → 渲染器保持 GL4ES → 点启动 → 进主菜单
```
