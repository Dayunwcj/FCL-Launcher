# 编译运行

工程结构：`:app` 是主模块（applicationId `com.doubao.mclauncher`，桌面入口是我们的 Compose 首页），
`:FCL` 是被依赖的库模块（FCL 原源码，含 `src/main/jni` C 代码与 `jniLibs` 预编译 .so）。

---

## 一、版本要求（照这个装，别改）

| 组件 | 版本 | 说明 |
|---|---|---|
| JDK | **17** | AGP 8.13 要求；用 JDK 11 会在配置阶段直接失败 |
| Gradle | **8.14.4** | 工程自带 `gradlew`，版本已在 `gradle/wrapper/gradle-wrapper.properties` 固定 |
| AGP | **8.13.2** | `gradle/libs.versions.toml` 里 `agp = "8.13.2"` |
| Kotlin | **2.4.10** | Compose 编译器插件必须同版本（`org.jetbrains.kotlin.plugin.compose`） |
| NDK | **27.0.12077973** | `FCL/build.gradle.kts` 里 `ndkVersion` 写死，换版本 CMake 行为会变 |
| CMake | **3.22.1** | AGP 会用它跑 `FCL/src/main/jni/CMakeLists.txt` |
| compileSdk | 35 | FCL 的 `compileSdk` 是 35 |
| minSdk | 26 | FCL 硬限制，Android 8.0 起 |
| 磁盘 | ≥ 8GB | 源码 ~1GB + Gradle 缓存 + NDK 产物 |

> 依赖里有一处特别的地方：FCL 用 `prefab = true` + `com.bytedance:bytehook:1.0.10`，
> CMake 里 `find_package(bytehook REQUIRED CONFIG)` 就是从那个 AAR 的 prefab 拿的。
> 别把 `prefab` 关掉，否则 CMake 第一步就报找不到 bytehook。

## 二、本地编

### 1. 装 SDK / NDK / CMake

Android Studio → Settings → SDK Manager：
- SDK Platforms：**Android 15.0 (API 35)**
- SDK Tools：**NDK (Side by side) 27.0.12077973**、**CMake 3.22.1**、**Android SDK Build-Tools 35**

命令行等价：

```bash
sdkmanager "platforms;android-35" "build-tools;35.0.0" "platform-tools" \
           "ndk;27.0.12077973" "cmake;3.22.1"
```

### 2. 指向 SDK

在工程根目录建 `local.properties`：

```properties
sdk.dir=/你的/Android/sdk
# Windows 下写成：sdk.dir=C\:\\Users\\你\\AppData\\Local\\Android\\Sdk
```

### 3. 编译

```bash
cd merge-工程
./gradlew :app:assembleDebug            # Linux/macOS
# 或 gradlew.bat :app:assembleDebug     # Windows
```

产物：

```
app/build/outputs/apk/debug/app-debug.apk
```

校验原生库真的进包了：

```bash
unzip -l app/build/outputs/apk/debug/app-debug.apk | grep arm64-v8a
```

必须能看到这几行（缺一行就说明 NDK 没编成功）：

```
lib/arm64-v8a/libpojavexec.so        ← JVM + GL 上下文 + 输入桥
lib/arm64-v8a/libpojavexec_awt.so    ← AWT 桥
lib/arm64-v8a/libfcl.so              ← dlopen/chdir/setenv 入口
lib/arm64-v8a/libandroidnsbypass.so  ← linker namespace 绕过
lib/arm64-v8a/libgl4es_114.so        ← GL4ES（预编译，来自 jniLibs）
lib/arm64-v8a/libbytehook.so         ← 来自 bytehook AAR
lib/arm64-v8a/libopenal.so           ← 来自 openal-soft AAR
```

### 4. 安装

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

或者把 apk 拷到手机点击安装（需要允许「安装未知来源应用」）。

## 三、GitHub Actions 编

### 1. 推仓库

仓库根目录必须**直接是** `merge-工程/` 里的内容（`settings.gradle.kts` 那一层）。

```bash
cd merge-工程
git init && git add -A && git commit -m "merge FCL backend"
git remote add origin git@github.com:你的账号/你的仓库.git
git push -u origin main
```

### 2. workflow

把下面内容存成 `.github/workflows/build-apk.yml` 一起推上去（本包 `scripts/` 里也有一份可直接拷）：

```yaml
name: Build APK
on:
  push:
    branches: [ main, master ]
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    timeout-minutes: 90
    steps:
      - uses: actions/checkout@v4

      - name: JDK 17
        uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '17'

      - name: Android SDK
        uses: android-actions/setup-android@v3

      - name: 安装 SDK / NDK / CMake
        run: |
          yes | sdkmanager --licenses > /dev/null || true
          sdkmanager "platforms;android-35" "build-tools;35.0.0" "platform-tools" \
                     "ndk;27.0.12077973" "cmake;3.22.1"

      - name: 编译
        run: ./gradlew :app:assembleDebug --no-daemon --stacktrace

      - name: 校验原生 so
        run: |
          unzip -l app/build/outputs/apk/debug/app-debug.apk | grep -E \
            "lib/arm64-v8a/(libpojavexec|libfcl|libgl4es_114|libbytehook)" || exit 1

      - uses: actions/upload-artifact@v4
        with:
          name: app-debug
          path: app/build/outputs/apk/debug/*.apk
```

### 3. 下载

Actions 跑完 → 该次运行页面最下面的 **Artifacts** → `app-debug.zip` → 解压得到 `app-debug.apk`。

### 4. 常见报错对照

| 报错 | 原因 | 处理 |
|---|---|---|
| `find_package(bytehook)` 失败 | `prefab` 关了 / bytehook 依赖丢了 | 检查 `FCL/build.gradle.kts` 里 `prefab = true` 与依赖 `libs.bytehook` |
| `No version of NDK matched the requested version` | NDK 版本不对 | 装 `ndk;27.0.12077973`，或改 `ndkVersion`（不推荐） |
| `Unsupported class file major version` | 用了 JDK 11/21 | 换 JDK 17 |
| `Kotlin ... was compiled with an incompatible version` | `:app` 与 `:FCL` Kotlin 版本不一致 | 两边都用 2.4.10 |
| `Manifest merger failed` | 两个模块都声明了 `android:name` | 本包里 FCL 库清单的 application 属性已被剥离，正常不会出现；自己改清单时注意 |
| `Execution failed for task ':FCL:externalNativeBuildDebug'` | 缺 CMake 或 NDK 未装 | 装 `cmake;3.22.1` |
